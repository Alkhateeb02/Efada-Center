## 🌟 Overview

**Efada Center** is a licensed center dedicated to special education and developmental rehabilitation. This portal provides an accessible, bilingual (Arabic RTL and English LTR) digital experience designed to connect families and specialists with comprehensive therapeutic, behavioral, speech, and educational services.

---

## ✨ Features

- **🌐 Full Bilingual Support (i18n):** Real-time switching between Arabic (RTL) and English (LTR) with localized typography and layout direction.
- **🎨 Brand Design System:** Cohesive identity with customized color palette, smooth micro-interactions, responsive navigation, and mobile drawer.
- **📋 Clinical Programs Showcase:**
  - Speech & Language Pathology (نطق وتخاطب)
  - Behavior Modification & ABA (تعديل السلوك وتحليل السلوك التطبيقي)
  - Occupational & Sensory Therapy (العلاج الوظيفي والتكامل الحسي)
  - Special Education & Early Intervention (التربية الخاصة والتدخل المبكر)
  - Physical Rehabilitation & Motor Skills (العلاج الطبيعي)
- **📅 Interactive Booking & Evaluation:** Integrated evaluation intake request form with department selection and preferred time slots.
- **♿ Accessibility (a11y):** Keyboard navigable, screen-reader friendly skip links, aria attributes, high contrast ratio.

## 🚀 Getting Started

No build step or dependencies required. Open `index.html` in any modern web browser or serve via any static file server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx serve
npx serve .
```
